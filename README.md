## Development

Requires [Bun](https://bun.sh).

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

## Deploy

Deployed on Vercel — connect this repository in the Vercel dashboard, or deploy from the CLI:

```sh
vercel
```
